The frame

what the server is, and is not

The reliability surface

The MCP server is the suite's RELIABILITY SURFACE for questions an agent asks mid-reasoning — who owns this path, who calls this symbol, what reads/writes this model, which cases cover it, how stale is the map — packaged so the map is ADVERTISED every session instead of REMEMBERED behind a CLI (§13: two reviews, 69 agents, proved no gate can force CONSUMPTION of the slice; discovery is the last lever).

NOT a rail

a tool fires when the model chooses it, so every lifecycle MOMENT (commit, push, PLAN/PENDING writes, publish, regen) stays on hooks and gates that fire on the event — the D7 lie-blocks, push-gate-guard, and a new fail-closed commit hook.

NOT a mutation channel

those lie-blocks are PostToolUse `Write|Edit|MultiEdit` and PreToolUse `Bash` matchers (templates/hooks.json:58/71/109), and pre-checkpoint.sh:37-46 already warns that a non-harness PLAN write "slips past the lie-block unseen" — an MCP writer is that bypass institutionalized, so no .kdbp writer ships until the tool carries the lie-block inside (shared guard module it REFUSES on) or an `mcp__gabe-map__` matcher is proven to fire.

NOT a blob

archmap ≈540K tokens, c4 ≈320K, wiring.json 10.6 MB against a 25k-token harness cap means every tool PROJECTS, caps, and NAMES its caps ("N more"), stamps `map@<head> · N behind`, and carries a `confidence` + "floor, never scope" line (map-as-scope recall 0.560 vs grep 0.900).

NOT graft

red-spec.md:191-193 bans `graft mcp`/`graft init` (third-party directives in every result), so the suite's tools add what graft cannot — the second arm, entity ownership, cases, drift, deltas — and never duplicate graft_find_code/graft_trace_calls/graft_find_all.

before the edit

Tools inform. Mid-reasoning questions — who owns, who calls, what reads or writes, which cases, how stale.

at the write

Rails hold. Hooks and gates on the event — plan-proof-guard, push-gate-guard, the fail-closed commit hook wave 0 adds.

after the beat

Nags remind. The standing pulse angles S9–S14 on the E8 tail, the after-the-fact backstop.
