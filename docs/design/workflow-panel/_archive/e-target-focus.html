Target & Focus — two elements, one saccade

Every surface the station has — the right rail, and proposals A, B and C — shows one element. Most real questions are pairwise: does this hook write the table that endpoint reads? Today that costs two clicks and a memory.

E mirrors two frames. Both portraits face the screen edges, both field stacks face the centre gutter, so the focus's OUT column and the target's IN column touch at the same y. Underneath, a relation bar names the actual edges — and their trust class, which no card in the station draws today.

Pick any element to set the TARGET. Press PIN on the command card to move it into the FOCUS slot.
