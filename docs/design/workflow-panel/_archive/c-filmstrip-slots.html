Filmstrip & slots — where am I, and what is this

The left 266px is the workflow: the journey's steps as a vertical strip, current one lit, each carrying its write-count bar. The right side is a fixed 4 × 2 slot grid — eight boxes that never move.

The extra box is the point: C has room for STRUCTURE as its own slot, so a model's columns and a store's fields stop competing with the tables an endpoint reads. A and B fold STRUCTURE into STORE because a single row has no eighth cell.

An endpoint has structure too — the shape it carries. Its payload and response move into that slot, so the eighth box is never dead for the one kind a workflow is made of.
