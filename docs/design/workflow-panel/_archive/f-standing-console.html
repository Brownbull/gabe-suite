Standing Console — a shorter dock, because the dock was holding the wrong things

Every global readout in the station today — tier, node budget, kinds-on, the 6 unmatched fetches, the 20 homing move candidates — renders inside panelAll's Sources rows. Select any element and all of it disappears. That is the inverse of every RTS: SC keeps resources and the minimap in separate compiled dialog files so the engine cannot reflow them with the selection.

Move those out and the dock only needs 200px. Look at the three floating regions: the global strip top-right that never blanks, the pin rail on the left edge (WC3's hero bar), and a minimap bottom-left — which the station does not have at all. Every game surveyed ships a persistent overview; this one has __uniCamFit and nothing else.
