## What is written

THE BLOCKS (all written only when the kinds arm is selected and the part ran; arms off = no key at all, D12)

1) Per endpoint (and per variant): `endpoints[<key>].inflight` = a LIST of rows in REQUEST ORDER (middleware by `order.runs` ascending, then dependencies in FastAPI resolution order with sub-dependencies before their parent, then route-wrapper callables [12b], then the handler; a site one call down sorts under the station that called it; ties by line, kind, name). Written as `[]` when the part ran and found nothing — an absent key always means "part off" (the `switches[]`/`tasks == {}` precedent). Request-scoped rows are complete; a process-scoped thing this endpoint meets is a short row carrying `ref` plus this endpoint's own `read_at`.

2) Top level: `forms["inflight"] = {"process": {<key>: row}, "rules": {<rule id>: {scope, dies, says, source}}}`.
   - `process` keys carry no line number (the ids-leaf law): `built-once:<file>::<Cls>.<attr>` · `setting-once:<file>::<Cls>.<setting or property>` · `cache:<file>::<qual>`. Each row adds `applies_to` (count of endpoints that carry a ref row with applies != false).
   - `rules` holds ONLY the rules some row used; a row carries the rule id, never free text. No `x:`-style id is minted: rows are addressed by (kind, carrier, name, set_at) and process rows by their map key — the §A4 V33 precedent (amendment-1.md:121). Record as D29.

3) Row keys
   always: `kind` (state · contextvar · dependency-value · background · lock · cache · built-once · setting-once) · `name` · `scope` (request | process | unknown) · `set_at` (file:line | "unknown") · `set_by` (the STATION: `middleware:<Cls>` | dependency fid | handler fid | `<file>::<Cls>.__init__`; "unknown" when no write was found) · `set_in` (middleware | dependency | route-wrapper | handler | init) · `read_at` [ {at, fn, in, via?} ] capped at INFLIGHT.read_cap with `reads_more: n` · `reads` (found | none in scope) · `dies` ('with the answer' | 'with the server process' | 'unknown') · `rule`.
   optional, any kind: `set_fn` + `set_via` (the write is one call down: the function holding it and the call site in the station) · `also_set_at` [file:line] (other writes of the same name in scope — tier3's four `usage_credential` writes are ONE row) · `set_cond: true` (the write sits under an if/loop/except/match) · `applies: false` (a pass-through arm above the site proves this path exempt, D19) · `from` {kind: header|state, name} · `ref`.
   state: `carrier` (request.state | app.state) · `receiver: "unproven"`.
   contextvar: `var` (`<file>::<NAME>`) · `label` (ContextVar's first string argument) · `reset_at` · `through: "structlog"`.
   dependency-value: `param` · `type` (annotation text) · `dependency` (key into dependencies{}) · `teardown` (copied from the dependency form).
   background: `param` · `task` (resolved fid, when a project function) · `args` [unparsed, cap 120] · `after_answer: true` · `queues` (found | none in scope | beyond one level) + `passed_at`.
   lock: `call` (unparsed, cap 60) · `held` (with-block | call) · `released_at` · `released: "when its transaction ends"`.
   cache: `fn` · `decorator` · `maxsize` (literal | "default 128" | "unbounded") · `as_dependency: true`.
   built-once (top level): `owner` (`middleware:<Cls>`) · `attr` · `class` · `class_at` · `holds` [ {attr, as, at} ] (the container attributes its own __init__ builds) · each read_at entry adds `call`, `key` (first positional argument through S.locals_once, as `_rate` reads it) and `scope` ("all" | [path prefixes] via P._path_prefixes).
   setting-once (top level): `setting` | `expr` + `fields` (a property, through S.resolve_self_attr) · `settings_class` · `value` + `state: "default"` + `env` + `declared_at` (the same keys contract `_arg` writes) · `hands_to` [ {attr, param?, at} ].

4) State words. scope: request | process | unknown. dies: the three of the brief, nothing else. reads: found | none in scope (NEVER "never read"). set_at/set_by: a site or "unknown". queues: found | none in scope | beyond one level (the last only when the BackgroundTasks parameter is visibly passed on as an argument). value state: default | defined | unknown. ## The detectors

WHERE THE PART LOOKS — stations, built once per function and memoised by fid (a dependency 79 endpoints share is read once). No repo-wide grep: a test conftest, a startup seed or an unreached helper is never a station, which by construction removes the truth reader's traps 1 (test writes), 3 (unreached caches) and 4 (startup locks — gustify's 8 advisory locks read as 0).
 S1 middleware: every `forms["middleware"]` form with `kind: project`, by `order.runs` ascending; node = its `method` fid (dispatch else __call__). Third-party/unknown classes are never walked.
 S2 dependencies: the handler's direct dependencies in `MW._dep_params` order, each preceded by its transitive `dependencies{}.subdeps`, each once (FastAPI solves a dependency once per request — fastapi/dependencies/utils.py:664-684). Node = what `P._dep_node` says FastAPI calls. A CALLED dependency expression (`Depends(factory(...))`, name ends in ")", the _a3_forms_mw.py:464 test) walks the nested def the factory `return`s by name and NEVER the factory body — that body runs at import, not in the request. No returned def found -> the station is skipped and counted in `stats.inflight.factories_unread`.
 S3 route-wrapper callables (12b).
 S4 the handler.
 Every station is read in its own body (nested defs, lambdas, classes excluded) plus ONE call level through `R.callee` (incl. self.m()), center-vendored files skipped via `G._is_center`. One visitor `_visit(fn)` yields (node, guards, cond): guards in `P._events`' own text form so `P._path_prefixes` reads them; cond as `S._self_assigns` defines it.

RUN ORDER: stations -> D6 built-once -> D7 setting-once -> D8 cache table -> per endpoint D1 state · D2 contextvar · D3 dependency-value · D4 background · D5 lock · process refs. PRECEDENCE when two detectors see one fact: a dependency whose callee is cached is ONE dependency-value row with `ref` (no second cache row on that endpoint) · a ContextVar set from a request.state read is two rows joined by `from` · a state write whose value is a header read carries `from: header` and no header row (a header is input, not in-flight state) · a parameter typed in F.INJECTED_TYPES is never a dependency-value.

D1 state. Shapes (single-node predicates lifted into the carrier leaf): write = Assign/AnnAssign/AugAssign target `<x>.state.<attr>`, or `setattr(<x>.state, "attr", v)`; read = `getattr(<x>.state, "attr", ...)` with the name through `S.resolve_const` (tier3's `_RATE_LIMIT_USER_ID_STATE_KEY`), or a Load `<x>.state.<attr>`. RECEIVER PROOF added on top (contract's `_read` stays receiver-agnostic so repeat{} cannot move): leaf of `<x>` in INFLIGHT.app_receivers -> carrier app.state, scope process, rule app-state; `<x>` a parameter annotated with a leaf in INFLIGHT.request_types, or the first non-self parameter of a middleware dispatch -> request.state; `self` -> not a row; anything else -> kept with `receiver: "unproven"`, scope and dies unknown. One row per (carrier, name) per endpoint; first write in request order is set_at, the rest also_set_at. `from`: the written value's own header hit, else a local bound from a header read (the `held` logic of `_state_setter`). Emits rule request-state only when a write with a proven receiver is in scope; read with no write -> set_at/set_by "unknown", dies "unknown", rule no-write-found. MUST NOT CLAIM: "never read" · that the object is destroyed (the row is about the carrier, as the brief rules for request.state) · request scope for `request.app.state` · a merge with a cookie or header of the same name (tier3 `referral_source`).

D2 contextvar. Shape: Call `<recv>.set|reset|get(...)` where `<recv>` RESOLVES (`P._resolve`, two import hops; `mod.NAME` through `m.imports`) to a module-level assignment (`_Mod.assigns` reads AnnAssign too — _a3_paths_read.py:94-97, gastify's form) whose value is a Call with leaf in INFLIGHT.contextvar_ctors. Never matched by method leaf alone — `dict.get` is not a read. Binder calls (leaf in INFLIGHT.contextvar_binders) give one row per keyword with `through: "structlog"`. dies: a `reset(<token>)` inside a `finally` of the SAME function as the set, or a scoped binder used as a `with` -> 'with the answer' + reset_at (rules cv-reset · cv-scoped); set with no reset -> 'unknown' (cv-no-reset); get with no set in scope -> scope and dies unknown, set_at "unknown" (cv-get-only). An accessor (`get_current_user_id()`) is covered exactly one level down; deeper is not read. MUST NOT CLAIM: that a no-reset value leaks, or that it dies with the task — nothing in the source says either (truth trap 11).

D3 dependency-value (in the piece's after_rows and D-013's three known instances; NOT in the brief's list — ASSUMPTION, behind OPTIONS.inflight_dep_values). Shape: a handler parameter whose `Depends` default, `Annotated[..., Depends()]` or module alias names a dependency that `P._dep_target` resolves; param->dependency read by an 8-line private reader, `MW._dep_params` is NOT edited (three other arms consume it). read_at = Load sites of the parameter in the handler. Rules: callee decorated by INFLIGHT.cache_decorators -> process, dep-cached, ref · every `return` of the callee is a bare Name resolving to a module-level assignment -> process, dep-module-object · `dependencies{}.teardown` true -> dep-teardown · else dep-solved. Only the handler's own parameters; a sub-dependency's parameters are not rows. MUST NOT CLAIM anything about an unresolved dependency (no row).

D4 background. Shape: a parameter annotated with a leaf in INFLIGHT.background_types (handler, dependency, or the callee one level down) and Calls `<param>.add_task(f, ...)`; also `background=BackgroundTask(...)` on a returned Response. Emits name = unparsed callable, task fid when `P._resolve` finds it, args, after_answer true, dies 'unknown', rule after-the-answer. A parameter with no add_task in scope still gets a row: `queues: "none in scope"`, or `"beyond one level"` + passed_at when the parameter is an argument of a call. MUST NOT CLAIM when the task ends, nor that a ContextVar is still set inside it (tier3 `drain_delete_loop` — undecidable from source).

D5 lock. Shapes: Call leaf in F.LOCK_CALLS whose receiver name does not match INFLIGHT.lock_not_receivers · Attribute call `with_for_update` · a str Constant matching INFLIGHT.lock_sql. held = with-block when the call is a With/AsyncWith item. Rules: with-block -> lock-with-block · a release (INFLIGHT.release_calls, or pg_advisory_unlock text) in a `finally` of the same function -> lock-released + released_at · with_for_update and xact advisory locks -> lock-transaction ('unknown' + released text) · else lock-open ('unknown'). MUST NOT CLAIM a lock the endpoint's scope does not reach, nor a release it did not see; a lock OBJECT (threading.Lock()) is not a lock row.

D6 built-once. For each project middleware class: `Cls.__init__` -> every `self.<attr> = <Call>` (`S._self_assigns`, its conditional flag -> set_cond) whose constructor is NOT a settings read. `class`/`class_at`/`holds` when `S._class` resolves the constructor in the repo (holds = its own __init__'s `self.x = <leaf in INFLIGHT.containers>(...)` or a dict/list/set literal). read_at = Load sites of `self.<attr>` in dispatch plus self.m() one level, each with guards -> scope. MUST NOT CLAIM an object built inside dispatch (per request), nor anything for a third-party class.

D7 setting-once. In the same __init__: every Attribute `<local>.<name>` whose local `S._typed_local` types as a settings class (`S._is_settings`). `<name>` in `S.fields` -> value/env/declared_at with `state: "default"` (the environment can override; never "the live value"); a directly assigned property -> `S.resolve_self_attr` (expr · fields · unresolved); otherwise `state: "unknown"` with `expr`. hands_to = the self attribute it is assigned to, or the built object's attribute plus the constructor parameter it fills. One row per (class, setting): first read is set_at, others also_set_at (gustify's window_seconds at :101 and :104).

D8 cache. A function met by a station — called in scope (R.callee) or itself the dependency — whose decorator name (`C._dec_name`) is in INFLIGHT.cache_decorators. Top-level row once; per-endpoint ref rows where met. Deeper reach is COUNTED, never listed: `stats.inflight.caches_deeper` from one `R.bfs` over `FN.roots` restricted to handler and dependency roots (the switches-arm "one past it only counted" precedent). MUST NOT CLAIM pure-versus-external, unreached caches, or the hand-rolled TTL cache of tier3 (no detector -> no row).

12b — NOT in the first landing; chosen by the dry run's `unknown`/`none in scope` counts on gastify and tier3: route-wrapper callables (slowapi `key_func`/`exempt_when`; gastify's user_id READ lives there) · `@app.middleware("http")` function stations (tier3 sets its ContextVars there; today they are only NAMED by `MW._unscanned`, counted here as `unplaced_middleware`) · module-level and `global`-built objects (gastify `limiter`/`metrics`, gustify `_breaker`). Until then those rows say no-write-found / none in scope — true, and said.
