Shallow Logic Maps

Two pieces of logic drawn by hand, top to bottom, before any generator is built: the API endpoint POST /setup/complete and the frontend route guard RequireSetup. Every step cites the line it came from. Pick a path in a table and its map walks that path.

    What the drawing taught

    for the approach

    The shape of a shallow map

    • Four layers, then collapse.Edge · dependencies · handler · one orchestrator. The level below that — the upserts, ensure_principal_household — collapsed without losing a path.
    • A candidate collapse rule.Expand a call whose branches change the caller's exit or its effects (claim: REPLAY · IN_PROGRESS · NEW). Collapse a call whose branches do not (an upsert always writes).
    • Gates live in five places.Middleware (429) · a dependency (401) · the schema (422) · the handler and service (400, 409) · the database (a constraint → 500, except the one race claim handles). The handler alone shows two of the five.
    • Effects can sit outside the handler.The auth dependency commits a new user before the key or the body is checked.

    Across elements

    • A frontend guard is decided elsewhere.RequireSetup's branch reads GET /me's setup_required, which is the backend branch has_setup. The map needs a "decided by" link from one element to another.
    • The two maps join.A successful POST /setup/complete invalidates the query RequireSetup reads, so the guard moves from Needs setup to Ready.
    • Exits line up with test statuses.This endpoint's own code exits 200 · 400 · 401 · 409 · 422 · 429 · 500. Its tests also assert 404, which no path here produces — those tests reach something else.
    • Paths are the unit, not functions.Ten paths for one endpoint, six for one guard: small enough to name, and each one is a sentence a reader can follow.

    Open checks

    before anything is built
    1. Does FastAPI run the dependencies before it validates the body?The map draws it that way; if so, a request refused with 422 still commits a new user row.
    2. A missing bearer header: 401 or 403?HTTPBearer with auto_error=True, on the installed FastAPI 0.135.3. Drawn as 401, unverified.
    3. What do the tests that assert 404 against this endpoint actually send?No path in this map exits 404.
    4. Which paths are "sensitive" to the rate limiter?SENSITIVE_PREFIXES in middleware/rate_limit.py decides whether this endpoint gets the tighter window.
    5. Is a constraint violation in the write block meant to be a 500?Only the idempotency race is handled; every other constraint rolls back and surfaces unhandled.
