Element Forms

Every kind of piece gets a form: the slots it must define, read in the order a call lives. A filled slot shows what the piece decided. An empty slot is a finding, the way a scorecard with no capping rule or no adverse-action code was a finding.

From scorecard to code

one slot per model rule

Each rule a scoring model had to define has a counterpart in a piece of app logic. The right column fills it from POST /setup/complete.

The form

14 slots · 5 bands · 5 states

Fourteen slots for every piece that carries logic, in five bands read top to bottom: what comes in, what decides, what it does, how it fails, how we know.

    What repeats across pieces

    • Refusals are text.A status and an English sentence, no stable reason — the setup endpoint, the history read, the pantry reset, the rate limiter, the stream's HTTP refusals. Every client piece swept reads the status only, and the setup screen shows “in progress” for consent required.
    • Declared contracts show only success.All three endpoints declare no refusal, so the OpenAPI the web and Android clients are generated from misses every one.
    • Look up, then insert — with no recovery.The pantry reset, the stream and the skills handler race on a unique key and answer 500 or drop a write. The setup claim already solves this with a savepoint; nothing reuses it.
    • One rule, several homes, nothing checking.quantity above 0 in the schema but not the table; notes capped on batch but not single; one flag as an API constant, an API setting and a web constant; SSE and WebSocket twins with different key rules.
    • Error states with no way out.RequireSetup's splash, the pantry's Retry button with no handler, a “Retrying…” toast gone in 5 seconds.
    • Paths leave no trace.Observability is missing or left to the framework on most pieces; where a failure counter exists, nothing reads it.

    What the map is today

    • Reach, not decisions.It records what a piece touches — tables read and written, commits, callers, tests per element. It records almost nothing a piece decides: no raise, no branch, no try/except.
    • Effects are the strong slot.function_insight's access ops, commits and sinks already fill Effects, a model's Writers and a schema's Consumers.
    • The short forms are one pass away.parse_schemas, parse_models and parse_flags already open the right nodes, then drop the keyword arguments that carry defaults, bounds and constraints.

    The first slice

    • FastAPI endpoints, three slots.Refusal reasons, the status contract (declared vs produced) and preconditions inside the handler: the raises in a handler and one call level, joined through except → HTTPException.
    • What it should print for POST /setup/complete.Declares 200. Raises 400 and two 409s. Every refusal is text with no code.

    The battery that proves it

    • Fires.A raise in the handler; a service error translated to a status; a declared 201 beside a produced 409.
    • Stays silent.A handler with no raise reads n/a; a refusal that carries a code raises no text finding.
    • Honest-empty.With the pass off, archmap, c4 and levels are byte-identical.
    • Mutation and determinism.Delete the except and the finding flips; two runs produce identical bytes.

    What the form learns

    • Add Mirrors.Where else this rule lives, and what checks they agree: schema vs table, single vs batch, Zod vs Pydantic, three copies of one flag, SSE vs WebSocket.
    • Pair a refusal catalog with a reason map.An endpoint lists its refusals; a client piece maps each one to its copy. A client's refusal slot can't be judged without the server's list.
    • Split repeat safety in three.Double submit · key scope, per attempt or per intent · response races.
    • Split defaults into client and server.The favorites read stops at 20 because an omitted limit means the server's default.
    • Add dead affordances, response use and inherited effects.A Retry button with no handler; a preview whose answer is dropped; a GET that commits through its auth dependency.
    • Add slots where the kind needs them.Cost per path for anything that spends money; lifecycle reset for stores; ordering for lists; key identity for throttles.
    • A sixth state: external.Flag values that live in the deploy platform otherwise read unknown forever.
    • Pure gates get their own short form.Six of the fourteen universal slots were n/a for the seed gate.
