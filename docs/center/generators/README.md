# The suite's OWN command centre — generators

`build_suite_center.py` renders `docs/site/center/` for the Gabe Suite itself: the skill roster, the hooks and
their enforcement ledger, the batteries (from `docs/center/data/facts.json`, GENERATED by `write_facts.py`), the
board, the docs backlinks and the prism pages. It is the suite's centre, not a project's: a project's centre is
built by `templates/center/generators/build_center_a3.py` from `center.config.json` + `adoption.json`.

| File | Role |
|---|---|
| `build_suite_center.py` | the orchestrator (two passes: the centre, then the docs' backlinks folded in) |
| `_suite_data.py` · `_suite_board.py` · `_suite_formats.py` · `_suite_surfaces.py` | the suite-side readers and renderers |
| `check_suite_center.py` | the gate — links, anchors, assets, unfilled tokens |
| `write_facts.py` | runs every `tests/*/run.sh` (serially, the doctor's exclusions honoured — ≈ 5½ min) and writes `docs/center/data/facts.json`: assertions · failures · status from each battery's own summary line, `protects` from its header, FIRE/SILENT from its own case labels, beat from the skill it names; `hooks` + `uncovered` are carried (authored). `--only <name>` re-records one battery in seconds. Run it before a regen when batteries changed — the Assertions tile reads it |
| `refresh_suite_center.sh` | `regen` (centre → prisms → docs → centre → the link gate → the diagram gate → the prism gates) or `check` — run from anywhere; every path is `$REPO`-absolute |

The A3 modules the suite board reuses — `_a3_render` · `_a3_board` · `_a3_guard` · `_center_data` · `_results_ingest` —
are imported from **`templates/center/generators/`**, the one source of record. The forked copies that lived here
(sixteen dead, five behind) were deleted 2026-09-10 after the centre-estate review; nothing is vendored twice.
Config: `docs/center/suite-center.config.json`. The shell it fills is `docs/center/shell/` (a deliberate fork of the
project shell — `board.js` and `a3.css` differ; sync is a ruling, not a drift).
