What this example is, and is not

It is the suite's domain example: a belt with a side input, a feedback loop, two human gates, and a named-gap ghost — shapes the software examples do not exercise. It is not a status page for gastify: every number is invented (operator ruling 2026-08-01), it does not update when gastify changes, and when the suite propagates to gastify's own command center the measured version gets built there, against real data, as its own page.

One consequence worth keeping in view: verify-prism.mjs passes these invented numbers exactly as it passed the ghosted ones — the gate checks a number is present, not traceable. On this page the lede and the source line carry the honesty instead. That division of labour is recorded in the skill.
