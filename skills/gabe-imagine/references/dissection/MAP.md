Two rules the whole map obeys:

- **Every element here is mined, not invented** — each file's practices carry
  a one-line source naming which corpus exhibited them. When a practice and a
  gate disagree, say so on the page rather than faking compliance.
- **The map is a router, not a chapter book** — a file that grows past ~120
  lines is trying to become a spec; split it or push detail back to the
  narrative record.
